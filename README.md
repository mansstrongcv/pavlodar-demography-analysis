# Demographics & Population Dynamics of Pavlodar Region (2009–2026)

## 📌 Project Overview
An analytical study examining demographic trends, urbanization rates, and population shifts in the **Pavlodar Region, Kazakhstan**. This project leverages official national statistics to visualize regional development and identify key social patterns.

## 🛠️ Tools & Technologies
* **Language:** Python
* **Libraries:** Pandas, Matplotlib, Seaborn
* **Data Source:** Bureau of National Statistics of the Republic of Kazakhstan (`stat.gov.kz`)

## 🎯 Key Research Questions
1. How has the population of the Pavlodar Region evolved since 2009 compared to national trends?
2. What is the current ratio between urban and rural populations in the region?
3. How do birth rates and migration impact local demographic sustainability?

## 📂 Repository Structure
* `data/` — Contains raw and processed CSV datasets from official statistics.
* `notebooks/` — Jupyter/Colab notebooks with data cleaning, analysis, and visualization code.
* `visualizations/` — Exported charts and figures for presentation.
